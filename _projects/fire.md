Fire is an open-source CFD solver built on ECOGEN. It uses adaptive mesh refinement to resolve shocks and reaction fronts in simulations of compressible reacting flows.

- [Source code and documentation](https://github.com/EarlFan/Fire)
- [Paper in Computer Physics Communications](https://doi.org/10.1016/j.cpc.2025.109881)
