ChatCFD uses large language models to turn natural-language requests into OpenFOAM simulation cases. It helps users set up cases, run simulations, and process the results through a conversational interface.

- [Source code and documentation](https://github.com/EarlFan/ChatCFD)
- [Paper in Advanced Intelligent Discovery](https://doi.org/10.1002/aidi.202500174)
